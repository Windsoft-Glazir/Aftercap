# AfterCap

**화면을 녹화하고 음성을 자막으로 바꿔, 매뉴얼·프레젠테이션·보고서를 만드는 Windows용 Windsoft 도구입니다.** Windows 10과 11을 지원합니다.

## 녹화부터 문서 내보내기까지

1. **화면 녹화.** 창 또는 화면 영역을 선택하고 시스템 소리, 마이크, 웹캠 영상(PIP)을 함께 녹화할 수 있습니다.
2. **자동 자막.** 내장 Whisper 음성 인식으로 음성을 자막으로 바꿉니다. 음성 인식은 PC에서 처리됩니다.
3. **문서 편집.** 자막과 대표 화면을 섹션별로 구성합니다. 섹션 목록, 편집기, 실시간 미리보기에서 제목, 본문, 캡처 화면을 다듬습니다.
4. **내보내기.** 사용 설명서, 프레젠테이션, FAQ, 일정표 등의 템플릿을 적용하고 HTML, PDF, Word(DOCX), PowerPoint(PPTX)로 내보냅니다.

## English

AfterCap turns Windows screen recordings into manuals, presentations, and reports. Record screen and audio, transcribe speech locally with Whisper, edit sections with representative screenshots, and export to HTML, PDF, DOCX, or PPTX.
