# AfterCap

화면을 녹화하고 음성을 자동으로 자막으로 변환해 매뉴얼, 프레젠테이션, 보고서를 제작하는 Windows 도구입니다.

AfterCap records your screen, transcribes speech, and turns the recording into manuals, presentations, or reports. It supports Windows 10 and 11.
